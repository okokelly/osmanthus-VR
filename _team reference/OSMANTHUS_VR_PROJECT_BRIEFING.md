# Summer Palace Osmanthus VR — Project Briefing

## 1. 项目是什么

这是一个约 4 分钟、运行在 Meta Quest 上的独立 VR 体验。

项目受到香水“颐和金桂”（英文暂定 **Summer Palace Osmanthus**）的启发，但目的不是宣传或销售香水。我们把它当作一个创作起点：**气味如何突然唤起一段遥远、模糊，却又非常个人的文化记忆？**

香水本身是抽象的，很难仅通过产品图片或语言被传达。因此，我们用 VR 把无形的气味转化成一个可以进入、触碰和经历的空间。

我们对 **The Old World** 的定义不是一个需要被复原的历史地点，而是：

> **A cultural memory recalled by scent.**

它与颐和园有关，但并不意味着体验者的家乡就是北京。颐和园长廊更像一个文化意象和记忆入口，指向长期生活在海外的人，对自己的语言、成长环境和文化身份产生的复杂乡愁。

这种记忆不是完整录像，而是碎片化的：有些部分很清晰，有些已经模糊，也会被现在生活的城市重新影响。

---

## 2. 核心概念三句话

> **The Old World is a cultural memory evoked by Summer Palace Osmanthus—fragmented by distance, yet carried through scent.**

> **Guided by drifting osmanthus, the user walks through the Summer Palace’s Long Corridor and awakens fragments of memory by touching three pillars.**

> **At the lake, these fragments reassemble with traces of the present into a new hybrid landscape, revealing that cultural identity is not recovered intact, but continually reconstructed through memory, distance, and lived experience.**

对应中文：

> 旧世界是一段被“颐和金桂”唤起的文化记忆；它因距离而变得碎片化，却依然被气味承载。

> 用户跟随漂浮的桂花穿过颐和园长廊，并通过触碰三根柱子，逐渐唤醒不同的记忆碎片。

> 最后，这些碎片在湖面与当下生活的痕迹重新组合成一个混合空间，说明文化身份并不是对过去的完整恢复，而是在记忆、距离与现实经历之间不断被重新建构。

核心逻辑：

**闻到气味 → 记忆被唤起 → 记忆以碎片出现 → 用户主动接触碎片 → 碎片在结尾重新组合 → 形成新的文化身份。**

---

## 3. 为什么选择 VR

这个项目的核心不是“展示一个漂亮的颐和园”，而是让用户亲自经历记忆形成的过程。

普通影像只能让观众观看；VR 可以让用户：

- 进入一段不稳定的记忆
- 跟随气味的视觉轨迹移动
- 主动触碰并唤醒记忆
- 观察环境随着自己的行为发生变化
- 最终站在一个被重新组合的文化空间里

因此，互动不是为了增加游戏性，而是为了表达：**记忆和文化身份需要由人主动寻找、选择和重新连接。**

## 4. 完整 User Journey

### 开场：气味出现

体验从一个安静、偏冷、边界模糊的空间开始。

用户看不到香水瓶，也不会出现产品广告。最先出现的是一小群暖金色的桂花粒子，它们代表气味，也承担视觉引导功能。

粒子从用户身边经过，进入远处不完整的长廊，用户跟随它们向前。

这部分要让用户感觉：不是自己主动决定回忆过去，而是某种熟悉的气味突然把记忆带了回来。

预计时间：约 20–30 秒。

### Scene 1：进入长廊

用户进入一个受颐和园长廊启发的空间。

它不是完整、写实的建筑复刻，而是一段正在形成的记忆：

- 一部分柱子非常清楚
- 一部分建筑消失在雾里
- 彩画可能只有局部发光
- 远处结构不连续
- 桂花粒子在空间中留下轨迹
- 色调偏冷、安静、低饱和

用户通过 Teleport 向前移动。桂花粒子、光线和声音共同告诉用户应该往哪里走。

Scene 1 表达的是：**记忆刚被唤起时，它仍然遥远而不完整。**

预计时间：约 40–50 秒。

### Scene 2：三根记忆柱体

长廊中有三根重要的可交互柱子。

用户用 Controller 靠近或触碰柱子。每次触碰都会唤醒一层记忆：

- 柱体上的彩画或纹理从暗变亮
- 桂花粒子从柱体中散开
- 一段影像、声音或空间碎片出现
- 整体环境逐渐从冷色走向暖色
- 用户手柄产生轻微震动

三根柱子不是三个随机互动，而是同一段记忆逐渐完整的三个层次：

1. **Place / Cultural Image**  
   园林、长廊、水面、窗格等文化视觉印象。

2. **Everyday Memory**  
   人声、脚步、家常声音、熟悉但无法准确定位的日常片段。

3. **Distance and the Present**  
   机场、列车、现代城市、异国语言和海外生活形成的距离感。

这些内容不需要写实呈现，可以是声音、投影、透明平面、漂浮纹理或建筑碎片。

当三根柱子全部被激活，桂花粒子会汇聚成一条新的路径，把用户引向湖面。

Scene 2 表达的是：**文化记忆并不是一个完整故事，而是由地点、生活和距离共同组成。**

预计时间：约 80–90 秒。

### Scene 3：Reconstruction

用户走出长廊，来到湖面前。

这里不是简单恢复成一个完整、美丽、真实的旧颐和园。否则结论会变成“通过怀旧回到过去”，这不是我们的概念。

Scene 3 中，前面唤醒的三组记忆碎片会重新出现：

- 园林屋檐和窗格
- 彩画和柱体碎片
- 湖面与传统建筑轮廓
- 海外城市的灯光、窗户或建筑形态
- 现代生活中的抽象影像
- 贯穿全程的桂花粒子

这些元素会在湖面上方缓慢移动、连接和重新排列，最后形成一个新的混合空间。

它既不是纯粹的颐和园，也不是用户现在生活的城市，而是一个只存在于这个人记忆中的第三空间。

桂花粒子在这里不再只是导航，而会连接碎片，帮助完成重组。环境从冷色逐渐转向温暖的金色，但仍保留少量冷色和现代城市痕迹。

最终可以出现一句话：

> **Cultural identity is not something we simply return to. It is something we continually reconstruct.**

Scene 3 表达的是：**生活在海外的人不会原封不动地回到过去；过去、距离和现在会共同形成新的文化身份。**

预计时间：约 60–80 秒。

### 结尾

最终空间形成后，用户有十几秒时间观察。

声音逐渐减少，只留下水声、风声和微弱的人声记忆。桂花粒子缓慢飘向湖面或天空，画面淡出。

体验总时长控制在 3.5–4.5 分钟。

## 5. 交互方式

为了控制开发范围和降低晕动风险，交互保持简单：

- Quest Controller
- Teleport 移动
- Snap Turn 转向
- Controller 射线负责传送
- 靠近、触碰或按 Trigger 激活柱子
- 不使用自由摇杆移动
- 不做复杂手势识别
- 不做分支剧情

用户需要完成的核心动作只有两个：

1. 跟随桂花粒子向前移动
2. 触碰三根柱子唤醒记忆

Scene 3 主要是用户触发后的视觉结果，不增加新的复杂操作。

## 6. 技术方案

### 基本配置

- Unity 6000.5.7f1
- Universal Render Pipeline
- Meta Quest 独立运行
- Android Build
- OpenXR
- XR Interaction Toolkit
- Input System
- Timeline 或简单状态机控制体验进程
- Unity MCP 协助搭建和修改场景

Unity 项目位置：

`/Users/kellyjia/Osmanthus`

Unity MCP 已安装，HTTP Server 使用：

`http://127.0.0.1:8080/mcp`

### 场景结构

为了降低风险，三个场景先放在**同一个 Unity Scene**中，作为三个连续区域：

```text
Start Area
    ↓
Long Corridor
    ↓
Three Pillars
    ↓
Transition Gate
    ↓
Lake / Reconstruction
```

通过雾、遮挡、转角、门洞和短暂淡出来隐藏区域之间的空间关系。

这样比三个独立 Scene 的加载和状态同步更稳定，也更适合一周项目。

### 视觉实现方式

我们不依赖复杂实时光照，也不一定需要烘焙。核心方法是“把光画出来”。

- 自发光材质：柱体彩画、桂花、远处光源
- 半透明雾片：制造朦胧感和空间深度
- Unity 距离雾：让远景消失在统一色彩中
- 假光轴：用锥体或交叉平面模拟光束
- 预先画好的光晕：避免真实光照计算
- 轻量粒子：表现桂花和记忆轨迹
- 可选 Bloom：真机性能允许时再开启
- 湖面使用简单 Shader，不做写实水体
- Scene 3 的倒影与城市碎片使用平面和透明材质模拟

这套方法的目标是让画面接近概念图，同时保证 Quest 性能。

## 7. MVP 与最终版本的区别

### MVP

MVP 的目标不是漂亮，而是证明体验完整成立。

需要完成：

- 用户能进入 Quest 体验
- 能够 Teleport 和 Snap Turn
- 能够从开头走到湖面
- 三根柱子可以依次触发
- 三次触发都有明确反馈
- Scene 3 会在完成互动后启动
- 总时长约 4 分钟
- 可以重新开始体验
- Quest 上稳定运行

MVP 中可以使用：

- Cube 搭建长廊
- Cylinder 作为柱子
- Plane 作为湖面
- 简单颜色区分三个区域
- 临时粒子和临时声音
- 简单位移动画代替最终重组效果

### 最终优化版

MVP 验收后再替换为：

- 长廊模型和屋檐
- 彩画纹理
- 更漂亮的桂花粒子
- 记忆影像和声音
- 雾片与假光轴
- Scene 3 混合空间
- 完整色彩变化
- 更自然的重组动画
- 最终音效和文字

原则是：**先完成完整体验，再替换视觉；不要一开始就精修一根柱子。**

## 9. 项目最难的地方

### 难点一：不要把它做成香水广告

香水只是记忆的触发器，不是体验中心。

需要避免：

- 大量展示香水瓶
- 品牌 Logo 成为主视觉
- 强调香调和产品卖点
- 把用户旅程写成产品体验流程

正确方向是：

> **We are not visualizing a product. We are using scent as a way to explore cultural memory.**

### 难点二：Scene 3 必须是重建，不是复原

如果结尾只是出现一个完整颐和园，概念会停留在怀旧和“回到过去”。

Scene 3 必须同时保留：

- 旧世界的文化碎片
- 距离造成的断裂
- 海外生活留下的新痕迹
- 用户在前三个互动中唤醒的内容

最后形成的应该是一个新的混合世界。

这是整个项目在概念上最重要，也最需要美术判断的部分。

### 难点三：没有语言说明时，用户是否知道该做什么

VR 用户很容易：

- 不知道该往哪里走
- 没注意到柱子可以触碰
- 错过视觉变化
- 在场景里停留太久
- 站错方向看不到动画

解决方式：

- 桂花粒子始终承担引导功能
- 可交互柱子在用户接近时轻微发光
- Controller Hover 时提供声音和震动
- 动画尽量发生在用户正前方
- 必要时加入非常简短的文字或语音提示
- Day 3 就进行陌生用户测试

### 难点四：Quest 性能

概念图中的暖光、雾、粒子和透明层在 Quest 上都有性能风险。

高风险内容包括：

- 太多透明雾片
- 太多粒子
- 多层透明材质重叠
- 实时阴影
- 高分辨率纹理
- 写实水面
- 全屏 Bloom
- Scene 3 同时出现太多碎片

解决方向：

- 使用 URP 和简单 Shader
- 尽量使用 Unlit、Emission
- 控制透明层数量
- 避免实时全局光照
- 减少动态灯光和阴影
- 真机测试优先于电脑 Game View
- 先达到稳定体验，再增加效果

### 难点五：四分钟的体验节奏

四分钟非常短。

如果长廊太长，用户还没理解概念就会结束；如果每根柱子动画太慢，用户会觉得是在等待。

建议：

- 触碰后 0.2 秒内出现反馈
- 每根柱子的主要变化控制在 10–15 秒
- 三根柱子之间允许用户自由观察
- Scene 3 重组控制在 40–60 秒
- 结尾留下 10–15 秒观察时间

### 难点六：多人协作与 Unity 合并

最大的生产风险之一，是每个人分别制作内容，最后一天才放入 Unity。

建议明确分工：

- 一人负责 Unity、Quest、交互和主项目
- 一人负责长廊、柱子、湖面和环境模型
- 一人负责粒子、记忆影像、声音与 Scene 3
- 新成员根据能力加入其中一个方向

素材提交时要统一：

- 尺寸单位使用米
- Pivot 位置正确
- 文件命名统一
- 纹理尺寸尽量控制在 1K 或 2K
- 不直接随意修改主场景
- 每天至少一次合并和 Quest 测试
